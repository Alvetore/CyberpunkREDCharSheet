# Cyberpunk RED — Автоматизированный интерактивный лист персонажа

Полнофункциональный, стилизованный интерактивный веб-лист персонажа для настольной ролевой игры **Cyberpunk RED**, оптимизированный для работы на **GitHub Pages** без необходимости в бэкенд-сервере.

---

## 🌟 Ключевые возможности

### 1. 100% Client-Side & Автономность (Без сервера)
- Работает полностью в браузере (Pure Static SPA).
- Все данные персонажей сохраняются в `LocalStorage` браузера в реальном времени.
- Никакой сервер, база данных или подписка не требуются.
- Готовый GitHub Actions workflow (`.github/workflows/deploy.yml`) для мгновенного бесплатного хостинга на **GitHub Pages**.

### 2. Двуязычный интерфейс (RU / EN)
- Мгновенный переключатель между русским языком (адаптированная терминология Cyberpunk RED) и оригинальным английским языком правил R. Talsorian Games.
- Подсказки оригинальных терминов (Dual Terms) рядом с названиями характеристик и навыков.

### 3. Автоматический расчет характеристик и состояний
- **10 базовых характеристик:** `INT`, `REF`, `DEX`, `TECH`, `COOL`, `WILL`, `LUCK`, `MOVE`, `BODY`, `EMP`.
- **Очки здоровья (HP):** автоматический расчет по формуле `10 + 5 * ceil((BODY + WILL) / 2)`.
- **Пороги ранений и штрафы:**
  - *Норма / Легко ранен* (HP > 50%).
  - *Тяжело ранен (Seriously Wounded):* автоматический штраф **-2 ко всем броскам** при HP ≤ 50%.
  - *Смертельно ранен (Mortally Wounded):* автоматический штраф **-4 ко всем броскам** при 0 HP + трекер штрафов спасброска от смерти (+1 за каждый ход).
- **Человечность и Эмпатия:**
  - Базовая Человечность = `EMP * 10`.
  - Установка киберимплантов автоматически снижает Человечность и динамически пересчитывает текущую Эмпатию: `floor(Humanity / 10)`.
- **Штрафы тяжелой брони:** автоматическое вычитание штрафа тяжелой брони (Heavy Armorjack -2, Flak/Metalgear -4) из показателей `REF`, `DEX` и `MOVE`.

### 4. Встроенный дайсроллер Cyberpunk RED
- **Бросок 1d10:**
  - **Критический успех (Взрыв десятки):** при выпадении натуральной 10 бросается еще один 1d10 и прибавляется к итогу (+ конфетти и киберпанк-звук).
  - **Критический провал (Единица):** при выпадении натуральной 1 бросается еще один 1d10 и вычитается из результата.
  - Вложение очков Удачи (LUCK) перед броском с автоматическим списанием.
  - Проверка против целевой сложности (DV) с расчетом перевеса (Margin of Success).
- **Бросок урона (Nd6):**
  - Поддержка любых формул (`2d6`, `3d6`, `4d6`, `5d6`, `8d6` и т.д.).
  - **Правило критических травм:** автоматическое распознавание двух или более шестерок (6, 6) с уведомлением: *+5 бонусного урона и критическое ранение!*
- **Спасбросок от смерти (Death Save):** автоматический бросок 1d10 + штраф раундов против характеристики `BODY`.
- **Процедурные звуковые эффекты:** синтезатор на базе Web Audio API (без внешних аудиофайлов).

### 5. Интерактивная таблица дистанций (Range DV Table)
- Полная официальная таблица сложностей стрельбы из книги правил Cyberpunk RED для всех типов оружия (Пистолеты, SMG, Дробовики, Штурмовые винтовки, Снайперские винтовки, Очереди).
- Клик по любой ячейке с DV на нужной дистанции мгновенно выполняет проверку атаки против этой сложности.

### 6. Модуль Нетраннинга (Cyberdeck & Netrunning)
- Кибердека: модель, слоты "железа", слоты программ.
- Каталог и менеджер установленных программ: *Booster* (Eraser, SeeYa, Speedy), *Defender* (Armor, Shield), *Attacker* (Sword, DeckKRASH), *Black ICE* (Hellhound).
- Трекер прочности программ (`REZ HP`) и статуса декомпиляции (Derezzed).
- Быстрые сетевые действия: *Scanner (DV 8), Backdoor, Pathfinder, Control, Eye-Dee, Virus, Slide, Jack Out*.

### 7. Критические травмы и броня
- Официальные таблицы травм головы и тела (бросок 2d6).
- Возможность бросить случайную травму или отметить полученную чекбоксом.
- Отображение штрафов и сложностей медицинского лечения (*First Aid, Paramedic, Surgery*).
- Раздельные зоны брони: Голова (Head SP) и Тело (Body SP) с кнопкой истирания (*Ablate -1 SP*) при пробитии и восстановлением.

### 8. Интерактивный конструктор персонажей (Все 3 метода из правил CPR)
Кнопка **«Конструктор»** в верхней панели:
1. 🐀 **Уличная шпана (Streetrats / Templates):** сверхбыстрый старт. Характеристики определяются броском 1d10 по таблице выбранной роли, готовый пакет из 86 очков навыков и тематический набор оружия, брони и имплантов.
2. ⚡ **Бегущий по краю (Edgerunners):** полу-кастомизация. Бросок 1d10 по таблице характеристик, предзаполненные карьерные навыки роли и свободный пул очков для индивидуальной донастройки.
3. 🛠️ **Полный конструктор (Complete Packages / Point-Buy):** полная свобода. 62 очка характеристик (значения 2-8), 86 очков навыков (с базовыми и x2 стоимостью) и стартовый бюджет 2,550 eb на оружие, броню и киберимпланты.

### 9. Интерактивный калькулятор урона и абляции брони
Кнопка **«Расчет урона и абляции»** в блоке ОЗ и в заголовке брони:
- **Зоны попадания:** Тело (Body) или Голова (Head — удваивает пробивающий урон $\times 2$).
- **Типы атак:** Обычная атака, Холодное оружие / Боевые искусства (игнорирует 50% SP брони цели), Бронебойные патроны AP (абляция -2 SP вместо -1).
- **Пуленепробиваемый щит:** поглощает урон первым до разрушения.
- **Детекция критических травм:** при выпадении двух и более шестерок ($6, 6$) автоматически начисляет +5 урона в ОЗ и бросает случайную травму по таблице 2d6.
- **Кнопка «Применить к персонажу»:** списывает HP, снижает SP брони и активирует полученную травму.

### 10. Интерактивный Жизненный путь (Lifepath)
- Генератор предыстории в один клик по таблицам Cyberpunk RED:
  - Культурное происхождение и языки.
  - Стиль одежды, прическа, особые приметы и манеры.
  - Жизненные ценности и отношение к людям.
  - Происхождение семьи и семейная трагедия.
  - Союзники, враги и несчастная любовь.
- Возможность редактировать каждое поле вручную или перебросить отдельный параметр.

### 11. Менеджер нескольких персонажей
- Переключение между несколькими персонажами в выпадающем списке.
- Создание новых персонажей, дублирование и удаление.
- **Экспорт в JSON:** выгрузка файла одного персонажа или бэкап всех персонажей сразу.
- **Импорт из JSON:** загрузка сохраненного листа с диска.
- Поддержка печати на принтер или в PDF (`Ctrl+P`).

## 🚀 Как развернуть на GitHub Pages

### Вариант 1: Автоматический деплой через GitHub Actions (Рекомендуется)

1. Создайте репозиторий на GitHub (например, `CyberpunkCharSheet`).
2. Инициализируйте git и отправьте код в ветку `main`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Cyberpunk RED interactive sheet"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ВАШ_РЕПОЗИТОРИЙ>.git
   git push -u origin main
   ```
3. В настройках вашего репозитория на GitHub перейдите в:
   **Settings** ➔ **Pages** ➔ в блоке **Build and deployment** выберите:
   - **Source:** `GitHub Actions`
4. GitHub Actions автоматически запустит готовый workflow из `.github/workflows/deploy.yml`, соберет проект и опубликует его по адресу:
   `https://<ВАШ_ЛОГИН>.github.io/<ВАШ_РЕПОЗИТОРИЙ>/`

---

### Вариант 2: Локальный запуск на компьютере

1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версии 18+).
2. Склонируйте или откройте папку проекта:
   ```bash
   cd CyberpunkCharSheetG
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
   Откройте ссылку в браузере (по умолчанию `http://localhost:5173`).

5. Для сборки статических файлов:
   ```bash
   npm run build
   ```
   Готовые файлы будут в папке `dist/`, которую можно загрузить на любой статический хостинг.

## 🛠 Технологический стек

- **React 19** + **TypeScript**
- **Vite 6** (мгновенная сборка, base: `'./'` для полной совместимости с подкаталогами GitHub Pages)
- **Tailwind CSS v4** (киберпанк-тема, неоновые акценты, срезанные углы `clip-path`)
- **Lucide Icons**
- **Web Audio API** (встроенный синтезатор ретро-звуков кубиков, кликов и выстрелов)
- **Canvas Confetti** (визуальное празднование критических успехов)
