# Cyberpunk RED — интерактивный лист персонажа

Браузерный лист с русским и английским интерфейсом. Персонажи хранятся в LocalStorage; доступны импорт/экспорт JSON, резервная копия коллекции и печать.

[Открыть приложение](https://alvetore.github.io/CyberpunkREDCharSheet/) · [Гараж и каталог транспорта](audit/VEHICLES_RU.md) · [Каталог снаряжения](audit/GEAR_RU.md) · [Киберимпланты и слоты](audit/CYBERWARE_RU.md) · [Исправления 23.10.2026](audit/FIXES_RU.md) · [Исходный аудит](audit/REPORT_RU.md)

## Возможности

- Единые эффективные характеристики, текущая EMP, HP, штрафы брони и ранений. Seriously Wounded: HP меньше половины максимума, округлённой вверх. Mortally Wounded: штраф −4 к действиям, MOVE −6 (минимум1).
- Броски 1d10 с критической10 / провалом1, ограниченным расходом Luck и строгим превышением DV. Death Save: результат с модификаторами меньше BODY, натуральная10 всегда провал.
- Урон Nd6 / Nd6+N, отдельные критические +5, щит без переноса остатка попадания, голова ×2 / Cracked Skull ×3, AP, Brawling, Melee / Martial Arts и прямой урон.
- Конструктор Streetrat, Edgerunner и Point-Buy: десять таблиц по десять строк, отдельные броски STAT Edgerunner,86 очков навыков, обязательные минимумы, культурный язык4. Point-Buy:62 STAT,2550eb снаряжения плюс800eb только на одежду / Fashionware; неиспользованная часть этих800eb сгорает.
- [Становление по структуре листа персонажа](audit/LIFEPATH_RU.md):12 основных полей в шесть рядов, отдельные строки друзей и романов, таблица врагов с причиной, ресурсами и планом действий. Одна форма в листе и конструкторе; старые заметки сохраняются.
- Каталог200 оружий с полными доступными описаниями и84 профилями, а также18 вариантов гранат из Data Pool. Метание: DEX + Атлетика, до25 м, с расходом одной гранаты при попадании и промахе; перезарядка не восстанавливает гранаты. Раздельные магазины разных типов патронов/ёмкостей; альтернативные режимы одного магазина расходуют общий запас. Дополнительный магазин изначально пуст: нажмите «Перезарядка». Складские боеприпасы автоматически не списываются.
- Все173 записи страницы имплантов Data Pool: основания, опции, щепки и улучшения. При добавлении доступен каталог карточек по12 разделам с поиском, ценой, HL и слотами. Покупка в инвентарь → установка в конкретные слоты; проверяются вместимость, совместимость и поддержанные требования. Кибероружие появляется в разделе оружия автоматически, сохраняет патроны при снятии и повторной установке.
- [Единый каталог рюкзака и последовательное добавление](audit/CATALOGS_RU.md):687 предложений в18 разделах —261 обычный предмет,200 оружий,18 гранат,35 видов брони/щитов и173 записи имплантов. Предметы можно хранить без использования, затем взять оружие, надеть броню или установить имплант. Патроны, режимы и текущая SP сохраняются; сменённая броня остаётся в рюкзаке. Карточки с поиском и выбором количества; подписки помечены как ежемесячные.
- Каталоги остаются открытыми после добавления: выбор, поиск и раздел сохраняются, появляется подтверждение. Можно последовательно добавлять снаряжение, оружие, импланты, программы, транспорт и улучшения транспорта до явного закрытия окна.
- Каталог транспорта:59 записей из гаража Data Pool, четыре раздела, поиск и карточки с ценой, ПЗТ, местами и скоростью. Полные описания, покупка за наличные или добавление уже имеющегося транспорта. Пользовательские машины, повреждения и улучшения сохраняются.
- Таблица дистанций выбирает подходящую категорию. Autofire расходует10 патронов, использует Autofire и при успехе считает2d6 × ограниченное превышение DV.
- Отдельные ранги Martial Arts, бюджеты Tech / Medtech, бонусы Solo, терапия Humanity, общий пул слотов кибердеки (Black ICE — два), Rez / Derez.
- Проверка импортов до замены коллекции. Повреждённое сохранение копируется дословно перед перезаписью; ошибка записи показывается пользователю. Экспорт JSON создаёт независимую резервную копию.

## Границы правил и DLC

Это лист с частичной автоматизацией. Исправлены подтверждённые ошибки базовых правил и проверенные расхождения с Weapon Rebalance / Black Chrome errata2026. Каталог восстановлен из публичного [Data Pool](https://alec-leon.github.io/data-pool/equipment/weapons/); вторичный источник не заменяет первоисточники RTG.

Условия экзотического оружия, ситуативные эффекты травм, специальные условия имплантов, часть DLC-приёмов и дерево Medtech требуют ручной проверки. Полные системы FBC, погонь, сложной NET-архитектуры,2070s Neuroport / Quickhacks и других опциональных модулей не реализованы. Наличие их имплантов в каталоге не означает автоматизацию соответствующих подсистем. Полное соответствие всем платным книгам и всем вышедшим DLC не заявляется. Подробности — в документах аудита.

Старые купленные предметы сохраняются как пользовательские записи: каталог не перезаписывает их параметры и модификации. Сверьте их с новой карточкой вручную. Для старых сохранений автоматические эффекты имплантов по умолчанию выключены, чтобы не удвоить ручные бонусы; включайте их соответствующим флажком.

У старых имплантов без привязки к слотам сохраняется прежнее состояние. В разделе «Киберимпланты» назначьте им основания через «Размещение / оружие»: повторная Humanity при таком переназначении не списывается.

## Разработка и публикация

Нужен Node.js22.

```sh
npm ci
npm test
npm run build
npm run dev
```

Тесты исполняют реальные TypeScript-модули и обработчики компонентов с изолированными React hooks, звуком и хранилищем. Это регрессионные проверки, не сертификация правил и не браузерные E2E-тесты.

`.github/workflows/deploy.yml` запускает тесты и сборку при push в `master`, затем публикует `dist/` в GitHub Pages. В Settings → Pages выберите источник GitHub Actions. Vite использует относительный `base: './'`.

Для повторного импорта оружия сохраните страницу Data Pool в `audit/source/weapons.html`, затем выполните `python scripts/import-weapons.py`; `--check` проверяет воспроизводимость без записи. Скачанные исходники и локальная книга правил в Git не включаются.

Импланты импортируются аналогично: страница [Data Pool](https://alec-leon.github.io/data-pool/chrome/implants/) → `audit/source/implants.html` → `python scripts/import-cyberware.py`. Проверка: `python scripts/import-cyberware.py --check`.

Снаряжение: пять страниц раздела [Data Pool Equipment](https://alec-leon.github.io/data-pool/equipment/) → `audit/source/gear-{items,clothes,agents,soft,acpa}.html` → `python scripts/import-gear.py`. Проверка: `python scripts/import-gear.py --check`; состав и границы описаны в [документации каталога](audit/GEAR_RU.md).

Транспорт: [Data Pool Garage](https://alec-leon.github.io/data-pool/workshop/garage/) → `audit/source/garage.html` → `python scripts/import-vehicles.py`. Проверка: `python scripts/import-vehicles.py --check`.

Стек: React19, TypeScript6, Vite8, Tailwind CSS4, Tiptap, Lucide, Web Audio API. Сборка предупреждает о крупном JS bundle; разделение каталога на динамические модули в этот выпуск не входит.
