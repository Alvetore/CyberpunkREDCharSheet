## Что исправлено

### P1

- **Throw снова наносит BODY напрямую по HP** (corebook стр. 177–179), а не урон рукопашной. Обновлён текст и тест (`audit-fixes.test.cjs`).
- **Death Save сбрасывается при стабилизации**: переход HP `<= 0` → `> 0` очищает накопленный штраф, травмы остаются (corebook стр. 188).
- **Заметки не переносятся на другого персонажа**: отложенное сохранение привязано к ID персонажа и снимку данных; добавлено сохранение при `pagehide`/`beforeunload`.
- **Повреждённое сохранение доступно для восстановления**: отдельный recovery-ключ, баннер, выгрузка копии и восстановление предыдущей коллекции. Обычный previous-backup больше не считается повреждением.
- **Старые данные нормализуются перед строгой проверкой**: отрицательные деньги/HP/SP/боеприпасы/SDP/quantity обрезаются, дубли ID чинятся, HP ограничивается максимумом. Структурно битые данные по-прежнему уходят в recovery.

### P1/P2

- **Гранаты**: общий `mergeGrenadeStack`; полностью израсходованный входящий стек не добавляет ёмкость; ручное добавление создаёт ровно одну гранату (1/1), а не 8; неизвестная граната из рюкзака больше не получает выдуманный `6d6`.
- **Валидация**: отрицательные `spMax`/`spCurrent` и нецелое/отрицательное `quantity` отклоняются; `hpCurrent` не может превышать максимум.
- **Fixer**: ранг Деловой хватки добавляется только к проверке торга (`fixerTradingBase`), а не к любой проверке Trading (corebook стр. 160).

### P2

- **Терапия требует проверки Медтеха**: СЛ15 для стандартной 2d6 и СЛ17 для экстремальной 4d6 (corebook стр. 229–230). Кнопки заблокированы без пройденной проверки; успешная проверка расходуется на один недельный курс; для Медтеха показывается запрет лечить самого себя. Есть ручной ввод итога и бросок `1d10 + база`.
- **Улучшения транспорта**:
  - каталог приведён к corebook стр. 163–165 и таблице цен Interface стр. 365 — 19 стандартных улучшений с правильными рангами и ценами;
  - установка требует выбранный транспорт, списывает цену, проверяет категорию/тип кузова, обязательное «Тяжёлое шасси», ранг Мото для Кочевника и запрет повторной установки там, где она не разрешена;
  - глобальный магазин больше не ставит улучшение на первую машину: цель выбирается в карточке, без совместимой машины покупка блокируется;
